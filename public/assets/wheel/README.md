# Wheel artwork drop zone

Future offline artwork for the Atonement wheel can be placed here. Suggested transparent PNG or SVG filenames:

- `tithe-10.svg`
- `turtle-dove.svg`
- `ram.svg`
- `ox.svg`
- `free-pass.svg`
- `spin-again.svg`

The current wheel deliberately uses short numeric/text callouts. When artwork is supplied, keep the callout as an accessible fallback and preserve the colour legend.
